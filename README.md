# DS/NEXUS — Data Science Student Portal

## Run locally
1. Extract this folder.
2. Open a terminal in this folder.
3. Run `python -m http.server 8000`
4. Open `http://localhost:8000` in your browser.

The PDF viewer loads PDFs with PDF.js from a CDN, so an internet connection is needed for the viewer library.
The included `pdfs/module1.pdf` through `pdfs/module5.pdf` are demo workbooks with 10 pages each.
Replace them with your own course PDFs while keeping the filenames unchanged.
Use **Change profile photo** on the page to select your profile picture; this only changes the photo in the current browser session.
